Help

How to use

  1. Pick a date from Calendar.
  2. Add your Focus for the day.
  3. Plan your day in 30-minute blocks.
  4. Use the right workspace tabs for Notes, Tasks, and Activity.
  5. Use Tasks for a global checklist grouped by time horizon and filter them with Task tags.
  6. Use Export regularly to back up your data.

Quick tips

  • Use Focus to hide both sidebars, then Full view to restore them.
  • Select a note card to open it, and use Labels to filter notes.
  • Use Search all notes to find notes across dates.
  • Tasks are grouped by Inbox, Today, This month, and Someday. Add Task tags such as Home, Work, or Waiting for context.
Data is saved locally on this device only. Export creates a backup text file you can import later.

How to use

  1. Use + Task to open the full Task editor in Inbox.
  2. Use + Activity to record an Activity entry.
  3. Use Planner to open Calendar and Today’s plan.
  4. Use Notes to open notes for the selected date.
  5. Use ? to open Help at any time.
  6. Use Export in the homepage footer regularly to back up your data.

Quick tips

  • In Tasks, switch between Inbox, Today, This month, and Someday, then filter the current list by tag.
  • In Notes, select a card to open it and use Labels to filter notes.
  • Select the required date in Planner before opening date-specific Notes.
  • Import and Last import are available in the homepage footer.
Data is saved locally on this device only. Export creates a backup text file you can import later.
